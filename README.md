# Sales Performance Analysis Dashboard

## 📊 Project Overview
Comprehensive sales analysis of 1,500 transactions across 5 regions and 7 product categories (2023-2025).
Built entirely using **Excel** with PivotTables, PivotCharts, and advanced formulas.

## 🎯 Key Insights

| Metric | Value |
|--------|-------|
| **Total Revenue** | $4.7M |
| **Total Transactions** | 1,500 |
| **Avg Order Value** | $3,151.93 |
| **Top Region** | North ($1.05M) |
| **Top Salesperson** | Bob ($856K) |
| **Best Product** | Tablets (2,577 units) |

## 📈 Analysis Performed

### Data Cleaning
- ✅ Identified 370 NULL values in Promotion column
- ✅ Cleaned data using Find & Replace (replaced with "NONE")
- ✅ Validated data quality before analysis

### Exploratory Data Analysis
- ✅ Sorting by revenue, quantity, and salesperson
- ✅ Filtering by region and product category
- ✅ Identifying top/bottom performers

### Calculations & Summaries
- ✅ Revenue by Region: `=SUMIF()`
- ✅ Quantity by Product: `=SUMIF()`
- ✅ Sales by Salesperson: `=SUMIF()`
- ✅ Conditional formatting for visual highlights

### Visualization
- ✅ PivotTable #1: Revenue by Region & Product
- ✅ PivotTable #2: Quantity by Product & Region
- ✅ PivotTable #3: Revenue by Salesperson
- ✅ PivotCharts: Column charts & Stacked columns
- ✅ KPI Cards: Professional dashboard design
